One quick setup step

So the Share button can appear on local HTML files.

File access is off — not set up yet
File access is on — you're all set

Chrome requires you to allow this extension to see local files. It's one toggle:

  1. Open the extension's details page
  2. Turn on “Allow access to file URLs”
  3. Come back here — this page updates automatically

Open any .html file from your computer and click the floating Share to html.cloud button. Your shares also appear under Your uploads on html.cloud.
